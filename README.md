# SpotClone 🎧

Полностью рабочий клон Spotify, который живёт целиком в браузере: **загружаете свои MP3 / M4A / FLAC / AAC / WAV / OGG** — и получаете привычный интерфейс с библиотекой, плейлистами, поиском, очередью и плеером.

Весь сайт — **один файл `index.html`**: CSS и JS встроены внутрь, внешних запросов нет.
Без бэкенда, без базы данных, без npm и без интернета. Ни один файл никуда не отправляется: музыка лежит в **IndexedDB** вашего браузера.

## Возможности

**Библиотека**
- Загрузка файлов кнопкой, перетаскиванием в окно (drag & drop) или целой папкой.
- Чтение метаданных прямо в браузере: **ID3v2.2/2.3/2.4 + ID3v1** (MP3), **MP4 `ilst`** (M4A/AAC/ALAC), **Vorbis comments + PICTURE + STREAMINFO** (FLAC), базово OGG/Opus.
- Обложки из тегов (APIC / `covr` / FLAC PICTURE) — в карточках, шапках и в плеере.
- Если тегов нет — берётся имя файла. Дубликаты (имя + размер) не добавляются.
- Сортировка по названию, альбому, дате, длительности; фильтр по библиотеке.
- Страницы альбома и исполнителя, плитки жанров из тегов.

**Метаданные и альбомы**
- Правка информации о треке: название, исполнитель, альбом, год, жанр, номер в альбоме.
- Замена обложки: картинка сжимается до 640 px и сохраняется в базе.
- Свои альбомы: название, исполнитель, год, собственная обложка, состав треков.
- Альбомы собираются «вручную» или автоматически по тегам; у своих альбомов страница с обложкой, перемешиванием и меню.

**Тексты песен**
- Синхронизированный текст (LRC) с подсветкой текущей строки и автопрокруткой — как в стримингах.
- Автопоиск в **LRCLIB** (бесплатно, без ключа и регистрации, CORS открыт).
- Текст можно вставить вручную и **расставить тайминги на слух**: играет трек, вы жмёте «Отметить строку».
- Клик по строке — перемотка на этот момент; импорт/экспорт `.lrc`; тайминги хранятся в библиотеке и попадают в ZIP-бэкап.

**Бэкап и перенос между устройствами**
- Экспорт **всей медиатеки** в ZIP: аудио + обложки + метаданные + тексты + плейлисты + альбомы + настройки.
- Экспорт **по частям**: отдельный трек, плейлист, альбом (кнопка ⬇ в шапке страницы или в меню «⋯»).
- Импорт с выбором «объединить» или «заменить», с защитой от дублей; частичные архивы тоже импортируются.
- ZIP можно перетащить в окно или выбрать прямо в «Добавить музыку» — откроется тот же диалог импорта.
- В архив кладётся `playlist.m3u8` — его можно открыть в VLC / foobar2000 и слушать без SpotClone.

**Плейлисты**
- «Мне нравится» + неограниченное число своих плейлистов.
- Создание, переименование (в том числе прямо в заголовке), удаление.
- Добавление через меню «⋯» или правой кнопкой мыши.
- Удаление трека из плейлиста / из библиотеки.

**Плеер**
- Полноэкранный плеер: клик по строке «сейчас играет» внизу (или по стрелке справа) раскрывает панель во весь экран — большая обложка,градиент по цвету обложки, перемотка, крупные кнопки, ссылки на альбом и правку данных. Закрывается стрелкой вниз или `Esc`.
- Play/pause, следующий/предыдущий, перемотка, громкость, mute.
- Shuffle и три режима повтора.
- Очередь воспроизведения с переходом на любой трек.
- «Недавно прослушано» на главной.
- Media Session API: клавиши ноутбука, центр управления macOS/Windows, экран блокировки Android.
- Горячие клавиши, включая русскую раскладку.

**Прочее**
- Всё сохраняется между перезагрузками: треки, обложки, плейлисты, громкость, shuffle/repeat, история.
- Если постоянное хранилище недоступно (инкогнито, песочница iframe, `file://`) — приложение не падает, работает в режиме памяти и предупреждает об этом.
- Адаптивная вёрстка.
- Демо-трек, синтезируемый в браузере, — чтобы проверить плеер без файлов.

## Быстрый старт

Нужен только один файл — `index.html`:

```bash
# любой статический сервер из папки проекта
python3 -m http.server 8080     # → http://localhost:8080
# или положить index.html на GitHub Pages и открыть оттуда
```

> ⚠️ Если открыть `index.html` двойным щелчком (`file://`), Chrome заблокирует IndexedDB: всё будет работать, но библиотека не сохранится после перезагрузки. Открывайте по `http(s)://` — например, `python3 -m http.server` или GitHub Pages.

## Публикация на GitHub Pages

1. Создайте репозиторий, например `spotclone`.
2. **Add file → Upload files** → перетащите **один файл `index.html`** → **Commit changes**.
   (Папки `src/` и `test/` не нужны — они только для разработки.)
3. **Settings → Pages** → *Source: Deploy from a branch* → Branch `main`, папка `/ (root)` → **Save**.
4. Через 1–2 минуты сайт доступен: `https://<логин>.github.io/spotclone/`.

Никаких подпапок, никакого риска перепутать регистр букв в пути — всё внутри одного файла. Работает и в корне домена, и в подпапке `/repo/`.

Обновить сайт = загрузить новый `index.html` поверх старого (или `git push`).

## Как править и пересобирать

`index.html` — **собранный** файл. Исходники живут в `src/`, сборка встраивает их внутрь:

```
src/index.html        разметка (ссылается на style.css и js/*.js)
src/style.css         все стили
src/js/tags.js        парсер метаданных ID3 / MP4 / FLAC / OGG
src/js/db.js          IndexedDB + кэш object URL
src/js/zip.js         свой ZIP-writer/reader для бэкапов
src/js/player.js      движок воспроизведения, очередь, shuffle/repeat
src/js/app.js         интерфейс, роутинг, загрузка, плейлисты
```

```bash
python3 build.py      # → пересоберёт index.html (~152 КБ)
```

Зависимостей у сборки нет — только Python 3 (он есть в macOS/Linux, в Windows через `python`).

Можно и не собирать: если правки мелкие, отредактируйте `index.html` напрямую (в начале файла есть комментарий-напоминание). Только учтите, что после этого `src/` и `index.html` разойдутся — `npm run test:build` сразу это покажет.

**Почему один файл — это удобно:** одна загрузка, нет проблем с путями и папками, сайт можно переслать в мессенджере и открыть локально, страница не делает ни одного сетевого запроса.
**Чем приходится платить:** файл ~152 КБ перекачивается целиком при каждом обновлении, диффы в git получаются крупными, а IDE хуже навигирует по коду. Для проекта такого размера это некритично, но если сайт начнёт расти — вернитесь к отдельным файлам (`<link>` + 4 `<script src>`), они лежат готовыми в `src/`.

## Альбомы и метаданные

**Правка трека.** Меню «⋯» у любого трека → «Изменить информацию…». Меняются название, исполнитель, альбом, год, жанр, номер в альбоме и обложка. Правки хранятся в библиотеке (сам аудиофайл не перезаписывается — браузер не имеет доступа к файлу на диске).

**Свои альбомы.** Их два вида:

* *автоматические* — группируются по тегу «Альбом» (появляются сами, ими нельзя управлять);
* *свои* — создаются кнопкой «Создать альбом»: название, исполнитель, год, обложка, затем выбор треков галочками.

Трек, добавленный в свой альбом, получает привязку к нему, а его поля «Альбом»/«Исполнитель»/«Год» синхронизируются с альбомом, чтобы поиск и сортировка оставались логичными. Убрать трек из альбома — «⋯» → «Убрать из альбома»; удаление альбома не удаляет треки.

## Тексты песен (синхронизированные)

Кнопка **🎤** в правом нижнем углу плеера (или клавиша `L`) открывает текст в полноэкранном плеере: обложка уступает место строкам, текущая строка подсвечивается и подтягивается к центру, прошедшие — гаснут. Клик по строке перематывает трек на этот момент.

**Откуда берётся текст.** По открытию панели приложение спрашивает [LRCLIB](https://lrclib.net) — открытую базу с LRC-таймингами:

1. `GET https://lrclib.net/api/get` — точное совпадение по исполнителю, названию, альбому и длительности;
2. если не нашлось — `GET https://lrclib.net/api/search` и выбор лучшего варианта (с приоритетом синхронизированных версий и близкой длительности).

Ключ не нужен, CORS открыт, запросы идут напрямую из браузера. Найденный текст кэшируется в треке (IndexedDB), поэтому второй раз в сеть не ходим. Если интернета нет или текст не найден — панель предложит вставить свой.

**Ручная синхронизация.** «Изменить» (карандаш) → вставляете текст (или загружаете `.lrc` файл) → «Синхронизировать»: включается режим расстановки.

* играет трек, вы нажимаете **«Отметить строку»** — текущей строке записывается текущая позиция, курсор уходит на следующую;
* можно ткнуть в любую строку списка — метка встанет именно ей;
* «Назад» снимает последнюю метку, «Готово» собирает LRC и сохраняет.

Сохранённый текст виден в панели, редактируется повторно (при правке текста старые тайминги сохраняются у строк с тем же содержимым) и попадает в ZIP-бэкап вместе с треком.

**Формат хранения** — обычный LRC:

```
[00:19.16] When you were here before
[00:24.09] Couldn't look you in the eye
```

Поддерживаются несколько меток в одной строке (`[00:10.00][01:00.50] Припев`), тег `[offset:]`, служебные `[ar:]`/`[ti:]` игнорируются.

## Резервные копии: экспорт и импорт ZIP

Кнопки **«Экспорт»** и **«Импорт»** — внизу левого сайдбара.

**Что внутри архива:**

```
library.json      треки, плейлисты, альбомы, настройки, тексты песен
media/<id>.<ext>  аудиофайлы как есть, без перекодирования
covers/<id>.<ext> обложки треков и альбомов
lyrics/<id>.lrc   тексты песен в формате LRC (с таймингами, если они есть)
playlist.m3u8     готовый плейлист для VLC / foobar2000 / любых плееров
readme.txt        краткая инструкция
```

**Скачать можно не только всё сразу:**

| Где | Что скачивается |
|---|---|
| «⋯» у трека → «Скачать трек (ZIP)» | один трек: аудио, обложка, текст, метаданные |
| Меню плейлиста → «Скачать плейлист (ZIP)» | все треки плейлиста + сам плейлист |
| Меню альбома → «Скачать альбом (ZIP)» | все треки альбома + обложка альбома |
| ⬇ в шапке любой страницы | то, что открыто: плейлист, альбом, исполнитель, «Мне нравится», все треки |
| «Экспорт» внизу сайдбара | вся медиатека целиком |

Имя файла собирается из названия (`spotclone-Дорожная музыка-2026-11-11.zip`), запрещённые символы `\ / : * ? " < > |` вырезаются. Манифест у всех архивов одинаковый, поэтому **любой** из них открывается через «Импорт» — можно перекинуть один альбом с телефона на компьютер и не тащить всю библиотеку.

**Как это работает:**

* архив собирается в браузере «с нуля» (свой ZIP-writer, метод STORE — без сжатия, чтобы не тратить CPU на уже сжатый MP3/FLAC);
* виден прогресс, размер архива ≈ размер медиатеки;
* при импорте можно **объединить** с текущей библиотекой (дубликаты по имени файла + размеру пропускаются) или **заменить** её полностью;
* читаются и чужие ZIP с методом DEFLATE (через встроенный `DecompressionStream`), но ZIP64 не поддерживается;
* если в архиве есть `lyrics/*.lrc`, но нет текста в манифесте (например, архив собрали вручную) — текст подхватится из файла.

Типичные сценарии: экспорт на компьютере → импорт на ноутбуке; скачал альбом на телефоне → открыл на ПК; отправил другу один плейлист архивом. Данные остаются локальными, ничего не загружается в интернет.

## Поддерживаемые форматы

Используется встроенный `<audio>` браузера, поэтому список форматов = список кодеков вашего браузера.

| Формат | Chrome / Edge | Firefox | Safari |
|---|---|---|---|
| MP3 | ✅ | ✅ | ✅ |
| M4A / AAC / ALAC | ✅ | ✅ | ✅ |
| FLAC | ✅ | ✅ | ✅ (Safari 11+) |
| WAV / AIFF | ✅ | ✅ | ✅ |
| OGG Vorbis / Opus | ✅ | ✅ | ⚠️ нет в старых Safari |
| WMA / APE / DSF | ❌ | ❌ | ❌ |

Если файл не проигрывается, появится сообщение — файл останется в библиотеке, его можно удалить через «⋯».

## Горячие клавиши

| Клавиша | Действие |
|---|---|
| `Space` | играть / пауза |
| `→` / `←` | ±5 секунд |

| `R` | режим повтора |
| `M` | выключить/включить звук |

## Где хранится музыка

- Файлы и обложки — как `Blob` в **IndexedDB** (база `spotclone`: `tracks`, `playlists`, `meta`).
- Плейлисты, громкость, shuffle/repeat и история прослушиваний — там же.
- Данные привязаны к **браузеру + домену**. Не чистите данные сайта и не пользуйтесь инкогнито, если нужна постоянная библиотека.
- Лимит — квота браузера (обычно десятки ГБ, ограничена свободным местом). Объём библиотеки и лимит показаны внизу сайдбара.
- Всё локально: ни один байт не уходит в сеть. По той же причине библиотеку нельзя перенести между устройствами — браузер не даёт скрипту читать файлы с диска.

## Ограничения и что можно добавить

Честно о том, чего нет:

- **Нет стриминга и общего каталога** — это локальный плеер, а не сервис: единственный источник музыки — ваши файлы.
- **Нет синхронизации между устройствами** — файлы лежат в браузере. Для синхронизации нужно облако (Dropbox, Яндекс.Диск, S3) и стриминг по прямой ссылке.
- **Перенос библиотеки — только через ZIP**: автоматической синхронизации нет (см. раздел про бэкапы).
- Нет PWA-офлайна (service worker) — для одного файла это, впрочем, почти не нужно.
- Автопоиск текстов работает только при наличии интернета и только через LRCLIB (другие базы либо платные, либо не отдают тайминги). Без сети текст можно вставить вручную.

Идеи для развития:

- [ ] Перетаскивание треков внутри плейлиста.

- [x] Синхронизированные тексты (LRCLIB + ручные тайминги).
- [ ] Караоке-режим по словам (LRCLIB отдаёт word-sync для части треков).
